# 便签墙 TODO（`@xia-sc/dsh-todo`）

[![License: MIT](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE) [![npm](https://img.shields.io/npm/v/@xia-sc/dsh-todo.svg)](https://www.npmjs.com/package/@xia-sc/dsh-todo)

把 TODO 当成便签贴在墙上：左侧边栏「便签墙」进入主面板，便签可以拖到墙上任意位置，单击弹出只读预览，双击原地展开编辑。状态只是便签里的一个字段，不是分区。工作区、起止时间、文档附件都是可选字段，留空就是一张普通便签。开启设置后，LLM 可以按需加载工具，读取和改写同一堵墙。

## 安装

### 从 npm 安装（推荐）

DSH 已连接 npm 时，直接以包名安装：

```js
plugin_manager({ action: 'install_bundle', target: '@xia-sc/dsh-todo' })
```

也可以在 **Plugins → 添加插件** 中填入同样的包名。

### 从本地目录安装（开发）

```js
plugin_manager({ action: 'install_bundle', target: 'E:\\path\\to\\dsh-todo' })
```

本地目录安装是链接整个目录；改完 `client.js`/`index.js` 后让插件管理器重载即可，不需要构建。

安装后刷新 Web GUI，左侧边栏出现「便签墙」。面板与设置文案随界面语言切换（zh / en），默认中文。插件设置保存在 `%DSH_HOME%\dsh-todo\config.json`，便签数据保存在同目录的 `tasks.json`。

## 任务字段

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 标题 `title` | **是** | 便签上的标题，最长 200 字。它是便签本身，不是业务前置校验 |
| 正文 `note` | 否 | 便签正文，最长 4000 字；放不下时在便签内部滚动 |
| 状态 `status` | 否 | `planned` 规划中、`active` 进行中、`done` 已完成、`cancelled` 已撤销；新建默认「规划中」 |
| 纸色 `color` | 否 | 六种暖色纸：`cream` 米黄（默认）、`lemon` 柠檬、`mint` 薄荷、`sky` 天空、`rose` 樱花、`lilac` 丁香 |
| 位置 `x` / `y` | 否 | 便签在墙上的像素坐标；旧数据没有时按网格自动补齐 |
| 关联工作区 `workspaceId` | 否 | 取自 DSH 的工作区清单；不选即不关联（在编辑态「更多字段」里） |
| 计划开始 `planStartAt` | 否 | ISO 时间；编辑态用日期时间选择器 |
| 预计结束 `planEndAt` | 否 | 可只填开始；编辑态默认不显示结束，点「+ 添加结束时间」才出现，可随时「清除」；结束早于开始时只提示不拦截保存 |
| 文档附件 `attachments` | 否 | 文档路径或链接的引用列表，最多 20 个；路径暂时不存在也能先记下，标为「文件不存在」（在「更多字段」里） |
| 子便签 `parentId` | 否 | 由 LLM 的 `todo_split` 产生；删除父便签只解除父子关系，不连带删除子便签 |

标题必填（便签必须有字）；工作区、两个时间、附件全部留空时，便签就是一张普通便签：墙上只有标题、正文和状态小标签，没有多余元信息行。创建流程不会用这些可选字段做前置校验。

状态只有上述四种，不增不减。

## 便签墙怎么用

- **贴一张**：点右上「新便签」，便签落在墙上的空位并原地展开编辑；保存后留在墙上。
- **摆放**：按住便签拖到任意位置，松手就停在那里并立即保存；靠近窗口上下边缘时会自动滚动。重叠也没关系，最近动过的便签在上层。
- **预览**：单击便签弹出只读预览卡，展示标题、正文、状态、时间、关联工作区与附件，不进入编辑态；点画布空白、Esc 或「关闭」收起。预览卡上有「编辑」按钮。
- **编辑**：双击便签（或双击预览卡、点预览卡里的「编辑」）原地展开——标题、正文、纸色、状态、开始时间都在便签上改；结束时间默认收起，点「+ 添加结束时间」展开、点「清除」收起，只填开始也可以。点「更多字段」可以选工作区、加/删文档附件。Esc 取消（有改动会二次确认），Ctrl/⌘+Enter 保存，删除需要点两次确认。
- **纸色与状态**：编辑态里选六种暖色纸；状态用右上角小圆点 + 文案表示；关联了工作区的便签会在状态标签右侧多一个小的工作区标签（虚线框，名字过长时省略）。已完成 / 已撤销的便签整张淡化，鼠标悬停或键盘聚焦时恢复清晰。
- **浏览**：顶部搜索标题、正文和时间；状态筛选 chips 带数量；工作区下拉可按「全部工作区 / 不关联工作区 / 具体工作区」过滤，引用已移除工作区的便签也有单独选项；底部状态条显示各状态张数与待完成数。
- **整理**：点「整理」按「状态（规划中 → 进行中 → 已完成 → 已撤销）→ 最近修改」把便签码成整齐的几列。
- **正文滚动**：便签固定 240 × 200，正文超出时只在便签内部滚动，底部有淡出提示，不撑大、不截断。

## LLM 工具与开关

工具**默认不注册**。开关在「设置 → 通用」或便签墙底部的 LLM 状态按钮里，值保存在 `%DSH_HOME%\dsh-todo\config.json` 的 `llmTools`（默认 `false`）。

开启后并不是一口气塞进三个工具，而是**按需加载**：

1. 模型先只看到 `todo_load_tools` 一个入口（描述里说明它能加载什么）。
2. 模型调用一次，三个墙工具才注册进**当前 agent 的作用域**，从下一步起可见可调用。子 agent 要各自加载。
3. 关掉开关：入口和已经加载的工具一起撤销；重新开启后需要模型再次调用入口。

| 工具 | 作用 | 主要参数 |
| --- | --- | --- |
| `todo_load_tools` | 按需加载入口：把下面三个工具加载到当前 agent | 无 |
| `todo_list` | 查看工具区（便签墙）内待完成的任务：默认只返回「规划中 + 进行中」，只读 | `status`（`pending`/`planned`/`active`/`done`/`cancelled`/`all`）、`workspace`（工作区 id 或标题片段）、`query`、`limit`（1–50，默认 20） |
| `todo_update` | 修改一张便签：标题、正文、四状态、工作区、起止时间、附件增删；`clear` 可清空可选字段 | `id`（必填）、`title`、`note`、`status`、`workspaceId`、`planStartAt`、`planEndAt`、`clear`、`addAttachments`、`removeAttachments` |
| `todo_split` | 拆解：把一张便签拆成多张子便签，保留父子关系，子便签默认「规划中」并继承父便签的工作区 | `id`（必填）、`subtasks`（1–12 个标题）、`note`、`status`（`planned`/`active`）、`markParentActive`、`inheritWorkspace` |

- **开启后**：只注册 `todo_load_tools`；调用后三个工具进入当前 agent 作用域，面板与工具调用同一套 operations。
- **关闭时**：注册被撤销（包括已加载到各 agent 的工具），工具不出现在工具表里，模型既看不到也无法调用；已创建的便签不受影响。切换立即生效，不需要重启。
- 便签的摆放位置与纸色由面板维护；LLM 工具不修改这两个字段。

## 数据位置

| 文件 | 内容 |
| --- | --- |
| `%DSH_HOME%\dsh-todo\tasks.json` | `{ "version": 1, "tasks": [...] }`，原子写入（临时文件 + 改名） |
| `%DSH_HOME%\dsh-todo\config.json` | `{ "llmTools": false }` |

`tasks.json` 手改坏时不会静默覆盖：原文件改名为 `tasks.json.corrupt-<时间戳>.json` 留档，再从空清单开始。旧数据缺少 `x`/`y`/`color` 时会在载入时补网格位置、默认米黄纸并回写。

## 限制

- 便签墙面板通过 Web GUI 自身的 HTTP 载体（`webServer`）读写数据，路由前缀 `/dsh-todo/api`。0.2.3+ 的每条路由都要求登录（`auth: 'required'`）；DSH 0.2.2-rc.5 的 `webServer` 不识别该字段，面板 API 没有登录门禁，仅适合本机回环使用。没有 `webServer` 的宿主（例如纯 CLI）里，agent 工具照常工作，只是没有面板。
- 便签纸是刻意的暖色纸板（六种固定纸色 + 纸面墨色），浅色和深色主题下都保持便签观感；界面壳层仍只用宿主主题 token。
- 附件是引用，不复制文件；删除原文件后附件行会标记「文件不存在」。
- 拖动用 pointer 事件实现，桌面鼠标与触屏都能拖；触屏上便签正文内部的触摸滚动会被拖动手势占用。
- 插件卸载不会删除 `%DSH_HOME%\dsh-todo\` 下的数据。

## 需求对照

| 需求 | 落地 |
| --- | --- |
| 1 任务可关联工作区 | `workspaceId`（可选）+ 编辑态「更多字段」里的工作区下拉 |
| 2 四种状态 | `planned`/`active`/`done`/`cancelled`，便签上的状态小标签 + 编辑态状态分段按钮，校验拒绝其他值 |
| 3 计划开始与预计结束时间 | `planStartAt`/`planEndAt`（可选），便签底部一行时间；编辑态填开始，结束按需添加/清除 |
| 4 文档附件 | `attachments`（可选），编辑态「更多字段」里增删、缺失标记 |
| 7 LLM 工具 + 开关 | `todo_load_tools` 按需加载入口 + `todo_list`/`todo_update`/`todo_split`；`llmTools` 默认 `false`，设置 → 通用里开启，关闭时连入口一起撤销 |
| 便签墙形态 | 自由摆放的暖色便签、纸色预选、原地展开编辑、整理、搜索与状态筛选 |
| 可选字段留空 | 仅标题必填；全空即普通便签，墙上只有标题、正文和状态标签，创建不做前置校验 |
| 开关默认关闭 | `config.json` 默认 `{"llmTools": false}`，工具默认不注册，底部显示「LLM 工具默认关闭」 |
